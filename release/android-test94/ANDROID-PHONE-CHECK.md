# test.94 Android手機檢查

覆蓋安裝原測試版，先到設定確認版本2026.10.16-test.94。

1. 開啟相集、返回、再開啟，確認照片能載入；頂部返回／多選按鈕可按。
2. 設定頁改一個紀念日，儲存後重開；確認日期保留、日期選擇可取消。
3. 選一個你願意測試、可讓傳輸持續至少10秒的檔案開始上傳，切到另一App，再鎖屏約30秒。回來查看傳輸中心的進度與最終收據。
4. 下載一個已屬於你帳戶的檔案，以同樣方式切App及鎖屏，再確認原檔／手機相簿保存結果。
5. 放大手機字體，確認按鈕與輸入框可操作；記下手機型號、Android版本及有問題的步驟。

若檔案在切App前就完成，該次無法驗證背景傳輸。一般切換／鎖屏與明確強制停止分開看；本輪沒有保證強制停止後自動續傳。iPhone後補，完整正式驗收仍需另外完成。
