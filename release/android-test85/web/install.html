下載 Android 測試版
  1. 下載後開啟 APK，依手機提示允許此來源安裝。
  2. 開啟「黃家小屋測試版」，使用自己的帳號與密碼登入。

這版的完整背景上下載仍在驗證；實體手機與不同廠牌的省電設定也待確認。請到傳輸中心核對每個檔案的實際結果。

請先更新 Android System WebView 與 Chrome。舊版網頁元件會顯示更新指引；較舊 Android 系統的背景傳輸尚未完成驗證。

背景傳輸需手機 App。手動強制結束可能中止或延後，請回來確認結果。

依手機查看安裝步驟

  1. 1. 用 Safari 開啟

    在手機的 Safari 中打開黃家小屋。

  2. 2. 分享並加入主畫面

    點「分享」；部分版面先點「更多」。接著選「加入主畫面」。

  3. 3. 確認以 App 開啟

    若出現「打開為網頁 App」，保持開啟，再點「加入」。

    開啟示意

  1. 1. 用 Chrome 開啟

    在 Android 手機的 Chrome 中打開黃家小屋。

  2. 2. 找到安裝選項

    點網址列旁的「更多」，選「安裝並建立捷徑」或「加入主畫面」。

  3. 3. 選擇安裝

    選「安裝」並依提示完成。若只有建立捷徑，尚不能確認為獨立網頁 App。

完成後，從主畫面開啟小屋；在這頁確認「已以獨立 App 視窗開啟」。

圖示與開關是操作示意，請在手機系統畫面完成。選單名稱可能依版本而不同。
